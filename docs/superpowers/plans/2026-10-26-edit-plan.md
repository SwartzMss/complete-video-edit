# Edit plan pipeline implementation plan

> Execute task-by-task with test-driven-development and verification-before-completion; request independent code review before PR creation.

**Goal:** Reproducible single-source cuts without changing existing tools.

**Architecture:** scripts/edit.py dispatches to editing/plan.py, media.py and pipeline.py inside the Skill. Pure plan validation and frame mapping; subprocess argument arrays without a shell.

**Tech Stack:** Python standard library, FFmpeg/FFprobe, unittest, GitHub Actions.

## 1. Plan and timeline
- [ ] Add tests/test_edit_plan.py: strict schema/types, missing source, ordered cuts, adjacency, empty cuts, full deletion, frame quantization and reasons.
- [ ] Run `python3 -m unittest discover -s tests -p test_edit_plan.py -v`; confirm missing implementation failure.
- [ ] Implement `load_plan(path)`, `validate_plan(data, duration)` and `timeline(data, duration, fps)` in editing/plan.py; distinguish requested/effective intervals.
- [ ] Run unit tests until passing.

## 2. CLI and media
- [ ] Add tests/test_edit_pipeline.py: three-color/tone fixture, copied Skill invocation, retained color/audio/order, substituted output failure.
- [ ] Cover no audio, boundary cuts, existing output, source fingerprint, malformed plan, audio offset and failed encoding.
- [ ] Confirm failures before implementing scripts/edit.py, editing/media.py and pipeline.py.
- [ ] Implement probe/preflight, hashing, shared time origin, frame-aligned trims, fixed profile, exclusive result directory and verify-before-publish.
- [ ] Run `python3 -m unittest discover -s tests -v` with real FFmpeg.

## 3. Documentation and delivery
- [ ] Add references/edit-plan.md and examples/edit-plan.json documenting CLI, schema, timing, output profile, limits, failures and human review.
- [ ] Update README, Skill and runtime reference; preserve existing tools and dependency lock.
- [ ] Add Ubuntu/Windows CI with FFmpeg and Python.
- [ ] Independent review; fix significant findings with tests; run full suite and `git diff --check`, commit, push and create PR for issue #1.
