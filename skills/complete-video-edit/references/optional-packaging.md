# 可选包装：按素材推荐

用于素材审查后简短介绍可选服务；实施细节仍以各效果参考为准。默认完整内容精剪、清晰原声和合理构图，不新增字幕或章节装饰。推荐不等于启用。能力实现状态以 [能力清单](capabilities.md) 为准；下表用于判断适用场景，不表示每项都有标准执行器。

| 选项 | 适用内容与建议位置 | 现有能力与实施入口 |
| --- | --- | --- |
| 补充说明文字 | 需要交代用户提供的额外背景时，在相关话题的安全空白处短暂出现 | 按配方设计字体、字号、配色、布局和淡入淡出；见 [说明文字](context-notes.md)，不等于对白字幕或图案贴纸 |
| 彩色电视花屏＋同步“哔”声 | 明确的话题切换，或已选定的精彩开头接正文；不打断半句对白 | 保存的彩条与蜂鸣素材，先核实文件；见 [彩条转场](tv-color-bars.md) |
| 熊出没片尾 | 完整讲述及自然收尾之后，用户希望搞笑卡通收场时；说明原模板约 34 秒，会增加总时长 | 随 Skill 分发的绿幕模板，使用前检查文件与哈希；见 [卡通片尾](cartoon-outro.md) |
| 小动物跑动进度条 | 有清晰阶段的叙述，画面存在不挡脸和动作的安全区域 | 可设计合成，不能默认声称已有通用模板；需按本片设计动物、条高、字级和位置，见 [视觉规则](visual-design.md) |
| 单图轻入场、轻推近；双图共同入场、逐张放大 | 讲到拍照、作品或实物时，且有对应照片 | 已有可复用做法；保留照片背景与主体比例，见 [图片插入](image-insertion.md) 与 [照片动画](visual-design.md)；缺照片时说明依赖，不虚构实物 |
| 局部特写、轻推近、画中画 | 清晰的精彩表情、动作或物品细节 | 按构图设计，见 [视觉规则](visual-design.md)；不裁掉关键动作，不频繁缩放 |
| 精彩片段开头 | 确有完整且能自然衔接正文的片段 | 需选片和设计衔接，属于改变默认顺序的可选方案；正文仍完整保留，不能复用旧视频的时间点 |

推荐时把效果落到这条素材上，例如：“基础版保留完整讲述、清理无意义停顿。可选：在讲到作品时插入对应照片；最后一句和动作结束后接熊出没片尾。连续口播中间暂不建议插彩条，容易打断叙述。”这只是表达示例，不是固定方案或默认效果组合。

仅在已检查素材后给出实际时间位置；未核实的片段不要编造时间。可选包装进入执行范围后，再读相应参考，记录选段与时间映射，并检查前后衔接。
