# 视觉包装：在完整叙述里突出重点

## 特写与画中画

| 内容信号 | 适合的处理 | 应保留的信息 |
| --- | --- | --- |
| 笑脸、歪头、突然想起来、自我纠正 | 轻微推近，然后自然回到主画面 | 原句上下文、表情前后的变化 |
| 拿起物品、关键手部操作 | 清晰时短暂局部特写，或保留主画面加局部画中画 | 手和物品的接触位置、动作全程 |
| 人的反应与物品细节同时重要 | 主画面保留表情，小窗展示细节 | 两路使用同一源时刻，不错位 |
| 普通叙述、信息密集段 | 稳定构图、清晰原声 | 讲述完整性 |

轻推近可以从原构图的 1.05–1.12 倍开始尝试，常见持续 2–4 秒；这些是起点，不是硬性套用参数。进出要柔和，避免频繁呼吸式缩放。原片低清、人物已贴边或放大会截掉关键动作时，不做放大。

同源画中画只是放大，不会增加细节，也不是另一个真实机位。先确认小窗确实能帮助看清；不要让一个模糊小窗盖住更有信息的主画面。通常单个小窗就足够，避开脸、手、字幕和物品运动路径。玩具会发声时保留同步原声，不用虚构配音补演。

## 顶部和底部如何分工

默认不新增章节、字幕、星星、标题板等。以下仅在用户明确要求添加文字包装时适用；不能因为存在模板或 ASR 文件就自动启用。烧录对白前必须校对，不确定的词不要编造。

- 顶部：当前章节名。进入新话题时轻微淡入/位移，稳定停留；章节名反映真实内容，不编造悬念或情绪。
- 底部：对白字幕，按语义拆分，通常一到两行。儿童语速、不完整句子和长停顿需要手动调整时间，不一律跟随 ASR 大分段。
- 小型章节进度可放在字幕之外的独立安全区，也可只在章节切换时出现；信息重复时省略。
- 日期、系列名、打卡天数仅在素材或用户已提供时使用，不从示例视频继承“第19天”等文字。
- 编辑提示采用明显不同的提示样式，且不伪装成对白。不要根据笑脸自动添加“开心坏了”等未经确认的心理描述。

## 构图与已有压制文字

优先使用原始干净素材（若已可用）；当前素材只有压制版时也可继续做合理预览。保持宽高比，不拉伸人物，不盲目用模糊背景填满所有空白。黑边可裁，但先确认不会剪掉原片信息。

已有标题、水印或压制字幕需要在全片取样定位，可能会移动。被遮住的像素无法靠裁切恢复。不要把大块不透明字幕条当默认解法：它可能继续遮住手和物品，削弱展示价值。可保留原字并把新增字幕移入独立区域；确需覆盖时确认覆盖区不包含额外可用信息，并说明限制。不要声称“恢复了原始画面”。

## 包装程度

从自然、轻量的版本开始：少量颜色、一致字体、直接剪切为主。主题和风格应随素材变化，不强制粉色、童趣或日记模板。每个视觉效果都要能回答“它帮助观众看见了什么”。优先减少无作用的装饰，不用高频转场掩盖粗糙的内容剪辑。

## 与讲述同步的照片动画

当用户提供照片、并授权放入对应话题时，默认先选择合适方式完成，不前置效果菜单。

| 触发实例 | 默认决策 | 必须审查 |
| --- | --- | --- |
| “讲到周末合照时放这张照片”，该段是普通叙述 | 单图居中淡入淡出 | 完整照片、原话题窗口、返回主画面 |
| 讲述时正在展示玩具，照片也需出现 | 单图画中画，选没有脸/手/物品运动的角落；无安全位置则换窗口 | 整个窗口内的运动路径，不能默认右上角永远安全 |
| 静态建筑或物品照片适合温和聚焦 | 单图缓慢推近 | 缩放后仍完整显示，不裁切照片主体；不冒充局部细节放大 |
| 同一话题两张照片且窗口充足 | 双图共同出现、依次放大 | 两图都能看清，现场动作不被遮挡 |
| 两张照片但窗口不足 | 更克制的、不重叠的单图窗口或重新审查定位 | 不擅自丢照片、不延长正文、不自动跨剪口 |

实现上单图使用 `photo-single`，`layout: center/pip` 与 `motion: none/ken-burns` 分开；进入/退出统一淡入淡出。`contain` 保持宽高比；缓慢推近从较小完整照片放大至仍在画幅内的完整照片，不做裁切式平移。画中画不压暗主画面。布局边界检查只能验证几何范围，不证明没有遮挡重要动作。

双照片的具体安排：

1. 从原片语句找到插入位置，再通过选段记录映射到成片时间。照片通常覆盖这一段画面而不延长或打断原声；若那段存在重要现场动作/反应，则缩短照片覆盖或采用画中画保留动作。
2. 两张照片可同时轻柔滑入，采用错落排布，短暂停留让观众看清两张。
3. 第一张移动到中央并放大，另一张淡出；然后第二张从原布局位置放大到中央，第一张淡出。
4. 结束时淡回原视频。完整照片主体不裁切，边框可用细白边；宽高比不匹配时可用克制的柔化照片背景，但不强制所有素材采用相同背景。
5. 用缓入缓出控制运动，避免突然跳变、过大弹跳和密集闪光。通常共同入场约 0.6–0.9 秒，概览约 1–2 秒，单图放大约 0.7–0.9 秒；停留时长以原声话题窗口为准。这些是设计起点，不是固定十秒模板。

两张照片不意味着可以推断人物关系、拍摄日期或场景因果，不额外编写说明性字幕。用户未指定顺序时按提供顺序或视觉连贯性安排，不猜照片中的人是谁。

照片文件本身不做生成式改脸或修图；布局、缩放和淡入淡出属于视频合成。FFmpeg 可用显式滤镜做简单动画；更复杂或需长期复用的布局可用 Remotion。生成新版本后检查共同出现、第一张最大、交接、第二张最大及返回原视频几个时刻，保证没有裁切、闪帧或残留图层。

需要可复用单/双照片动画时，使用 [Remotion 集成流程](remotion-integration.md)：独立视觉计划引用精剪结果，时间通过 `timeline.json` 解析。模板参数控制照片、窗口、大小与过渡，不复制某次素材路径。用 Studio 预览，`--stills` 导出关键阶段检查，局部范围不重置动画。源位置已删除或窗口跨剪口时先重新审查定位，不自动补齐。普通静态合成继续优先 FFmpeg。

只改视觉时优先复制已有音轨；若技术上允许，比较修改前后音轨哈希，确认原声没有变化。为局部修改导出带前后衔接的短预览，并提供完整成片。

## 成功交付后的简短提示

只有实际完整成片已生成且通过技术验收，才说明本次所用方式并简短介绍适用的其他已实现方式；技术验收与构图/遮挡/声音审查分别陈述。不要求用户前置选效果，不默认渲染多个版本。

- **默认自动选择并成功交付：**“本次照片采用淡入淡出，也可换成缓慢推近或画中画；需要时只调整照片部分并输出新预览和成片，沿用正文与原声。”
- **用户已明确指定：**“已按要求使用右上角画中画。”不附其他样式推荐；用户说不要建议时同样省略。
- **照片数量限制：**只有一张照片时不推荐双图效果；双图效果仍可用于两张照片。滑入尚未实现，不作为可选方式宣传。
- **失败或仅有预览：**例如“照片读取失败，尚未生成成片”，或“已生成局部预览，完整导出尚未完成”；不使用成功交付提示。
- **要求切换：**从既有精剪结果修改视觉计划、准备新工作区并输出新版本。无需重剪正文或更改剪点，完整音轨复制；画面重新编码，预览音频裁切重编码。不要把视觉上的“只改照片部分”描述成文件的无损局部修改。
