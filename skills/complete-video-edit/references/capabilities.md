# 能力清单与对话提示

本文件是 `complete-video-edit` 可选能力的单一能力状态与提示策略入口。Skill 的核心原则仍是完整保留信息与原顺序、优先原声、默认不加装饰；清单中的能力不会因此自动加入视频。每次只在与当前请求相关时展开，素材存在、配方完整或 Remotion Agent Skills 可用，都不等于已实现标准执行器。

## 当前能力

状态只说明本仓库提供什么：

- **implemented**：仓库内有可调用的标准命令或参数化工作流；使用前仍需满足依赖并验证本次结果。
- **recipe_only**：有制作规则、素材或范例，需要按任务情况辅助制作；没有统一的一键执行器。
- **planned**：尚未实现，不能作为当前可选功能宣传，也不能声称已运行。

| 能力 | 状态与入口 | 依赖/资源 | 边界 |
| --- | --- | --- | --- |
| 完整内容精剪 | `implemented`；`scripts/edit.py check/render/verify`，见 [精剪执行说明](edit-plan.md) | Python 3.10+、FFmpeg、FFprobe | 单原片、原顺序、正常速度的计划式精剪；未列入删除计划的内容默认保留 |
| 单/双照片包装 | `implemented`；`scripts/visual.py prepare/render` 与 `remotion/`，见 [Remotion 指南](remotion-integration.md) | 单图 PNG/JPEG/WebP；渲染需要 Node 22+、锁定的 Remotion 依赖、浏览器与 FFmpeg；照片依照本地时间线窗口安排 | 单图淡入淡出、完整构图缓慢推近、画中画；双图共同入场和依次放大。须检查实际遮挡；不是自动挑图或识别人脸 |
| 转写初稿 | `implemented`；`scripts/transcribe.py`，见 [本地环境指南](local-runtime.md) | 独立 Python 环境、锁定依赖；首次模型使用需下载 | 自动稿需人工校对；ASR 不自动决定删剪或认定无语音 |
| 用户提供的抖音参考下载 | `implemented`；`scripts/download_douyin.py`，见 [下载指南](douyin-download.md) | 用户授权的链接、网络、固定版本的独立上游后端及 FFmpeg/FFprobe | 不自动分析或加入成片；账号/批量等不支持场景按下载指南处理 |
| 素材可用性检查 | `implemented`；`scripts/check_assets.py`，见 [素材清单指南](asset-manifests.md) | Python 3.10+；媒体探测/抽样解码另需 FFprobe/FFmpeg | 检查登记素材，不下载；开头抽样解码不等于浏览器预览、全片解码或成片验收 |
| 彩条转场与同步蜂鸣音 | `recipe_only`；素材与做法见 [彩条指南](tv-color-bars.md) | 仓库内彩条/蜂鸣音素材；转场时长、音量与衔接需按素材制作 | 按请求加入；当前没有标准化的一键转场执行器，授权状态以清单声明为准 |
| 用户指定的高光前置 + 彩条 | `recipe_only`；遵循彩条指南与当前剪辑配方 | 用户明确给出的时间/事件，或确认已定位的候选区间 | 仅复制指定片段放在完整正片之前，正片仍保留原顺序；不能擅自自动挑选“最精彩”片段，也没有标准化的一键片头执行器 |
| 熊出没式卡通片尾 | `recipe_only`；见 [片尾指南](cartoon-outro.md) | 有台标的绿幕模板只在本机，不随仓库分发；需先检查或按用户指示准备素材 | 不是可编辑工程或一键模板；优先按配方替换绿幕窗口，不能声称本机已安装素材 |
| 自动判断“最精彩”片段 | `planned`；当前没有自动选段功能 | 暂无 | 不可用；当前可辅助查找候选，但须用户确认片段 |
| 标准化一键高光片头执行器 | `planned`；当前只有配方 | 暂无 | 不可用；用户指定片段后才能按配方辅助制作，完整正片保留原顺序 |
| 单图独立滑入方式 | `planned`；当前 Remotion 单图模板未实现 | 暂无 | 不可用，不得作为可切换样式推荐；既有双图模板已有共同上移入场 |

有权限/来源或本地文件不明确时先如实说明。资源清单的 `unknown` 不等于允许再分发；当前机器缺少本地素材时也不把它描述为已就绪。不要因清单列出一项能力就猜测依赖、许可证、素材或用户授权状态。

## 什么时候介绍能力

能力介绍不应延误或替代用户当前任务。结果和文件链接始终优先，主动提示控制在一到两句话；同一活跃任务/对话已经介绍过，或用户表示不需要建议后，不重复。

| 对话场景 | 做法 |
| --- | --- |
| 用户明确问“这个 Skill 能做什么？” | 简要分层概览：可执行的标准能力、需要素材/按配方制作的能力，以及尚未实现的功能。依赖和本机素材状态按需补充；不将计划中项目列为当前可用 |
| 用户只说“帮我精剪视频” | 先照常完成基础精剪。完整成片生成并通过技术验收后，默认在结果后用一句话提示少量功能类别，例如照片包装、彩条转场、卡通片尾配方；不要展开淡入、画中画等照片细节，也不自动添加这些效果 |
| 用户要求插入照片或询问照片样式 | 先按视觉规则选择合适的已实现方式并完成请求。成功完整交付后，说明本次实际使用方式，可简短给出与照片数量相符的其他已实现方式；失败、只有局部预览、依赖或照片缺失时不使用成功话术 |
| 用户明确指定样式，或要求不要其他建议 | 直接按指定执行；交付只说明实际采用效果，不附同类推荐，不再提示其他能力 |
| 用户提出高光开场但未给片段 | 先请用户给出时间区间/事件，或确认候选区间。不能仅凭 ASR、音量、表情等声称自动找出精彩段 |
| 用户指定片段并要求“先放这一段，再完整播放” | 按配方复制片段到正片之前，再接完整正片；不从正片中移动、删除或重复重剪叙事，不声称已有一键执行器 |
| 呈现失败、只有预览，或未完成技术验收 | 说明实际状态、受阻依赖和可行的下一步；不说成片已完成，也不附成功交付后的功能提示 |

未请求的照片、彩条、蜂鸣音、片尾、高光开场、字幕或配乐一律不自动加入。基础精剪后按需提示功能类别，不代表已就素材适配、授权、可用性或最终渲染背书。

## 对话示例

**只要求基础精剪**

> 用户：“帮我完整精剪这段视频。”
>
> 处理：不前置罗列效果或让用户选方案；按已确认的剪辑计划完成基础精剪。
>
> 成功交付后：“已完成精剪，成片和剪辑记录在这里。以后如需要，也可以加照片包装、彩条转场或片尾配方。”

**要求插入一张照片**

> 用户：“把这张合照放在讲周末出游那一段。”
>
> 处理：结合原画面动作和照片窗口选淡入淡出、缓慢推近或不遮挡内容的画中画；先完成一次成片，不批量试做候选版本。
>
> 成功交付后：“本次合照用淡入淡出。当前也可改为缓慢推近或画中画；如果你想换，我可以只更新照片包装并输出新预览和成片。”

**用户已经指定照片方式**

> 用户：“这张照片放右上角，用画中画；不要其他建议。”
>
> 交付：“已按要求完成右上角画中画，完整成片和预览在这里。”不追加替代菜单。

**询问能力列表**

> 用户：“这个 Skill 除了精剪还会什么？”
>
> 回答：先区分标准命令（精剪、转写初稿、可选照片包装、素材检查）、配方制作（彩条/蜂鸣音、用户指定的高光前置、卡通片尾），并指出自动高光选择、一键高光片头与单图独立滑入尚未实现；仅在用户要用时展开具体依赖和素材状态。

**没有指定高光片段**

> 用户：“做个精彩片段开场，加彩条，后面还是完整正片。”
>
> 回答：“可以按配方复制高光片段，再接完整正片；我不会自动判断哪段最精彩。你希望用哪个时间区间或哪件事？也可以让我先列出候选时间供你确认。”

**指定了时间区间**

> 用户：“把 00:35–00:39 放开头，加彩条，然后完整播放。”
>
> 处理：将指定区间作为高光副本放在开头；完整正片从原顺序开始保留，不把片段挪走或删掉。若当前环境没有标准化片头执行器或素材缺失，说明按配方制作的实际边界和所需条件。
