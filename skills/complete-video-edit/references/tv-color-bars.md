# 可选：彩色电视花屏转场

用户已认可的是七色电视测试条及底部色块，不是黑白雪花噪点。用户说“用保存的彩色电视花屏／彩条转场”时使用本素材；仅说“花屏”且上下文不明确时，先区分两者。

## 本地素材

- 相对 Skill 根目录：`assets/tv-color-bars/template.mp4`。
- 参数：1080×608，约 0.7 秒，无音轨；来源与哈希见同目录 `manifest.json`。
- 来自用户指定的抖音合集，已提取彩条段并裁去上下黑边，无播放按钮、教程界面或新增文字。
- MP4 随本 Skill 的 GitHub 仓库一起保存，安装或迁移时保留完整 assets/tv-color-bars 目录。缺文件时按 manifest 来源和裁切记录恢复，或请用户提供素材，不要改用黑白雪花。

可先运行 `python scripts/check_assets.py --decode`。清单 v1 将视频和蜂鸣音分别放在 `files[]`，分别检查文件、哈希、探测和授权声明；字段与安装行为见 [素材清单说明](asset-manifests.md)。来源与使用偏好不会自动成为再分发授权。

## 使用方式

- 仅按用户请求加入，不成为每条视频的默认包装。
- 可从 0.2–0.4 秒开始试，已认可示例是 29 fps 下 9 帧（约 0.31 秒）；按实际节奏调整。
- 彩条是图形素材，可适配成片画幅；保留全部七色和底部色块，不用居中裁切丢掉两侧颜色。已认可的 3:4 示例将图形铺满画幅，人物素材仍保持自身比例。
- 用户已明确要求：使用这款彩条转场时默认配同步短“哔”声，除非当次明确要求静音。纯画面 template.mp4 与配套 beep.wav 分开保存；不要因 MP4 无音轨而漏掉音效。
- beep.wav 是本地合成的 1 kHz 单声道蜂鸣音，48 kHz，0.7 秒，峰值约 -20 dBFS。按彩条实际持续时间裁切，并在裁后的首尾做约 8/12 毫秒淡入淡出；与彩条同时开始、同时结束。较长转场应重新生成对应时长，不循环引入断点。音量以不压过讲话为准，检查输出峰值与衔接；不要称其为来源视频的原声音效。
- 核对输出音轨中确实存在蜂鸣音。仅改声音时复制视频码流，保留画质、帧率、章节进度与正文内容。
- 精彩片段前置需用户指定或确认具体区间。将该区间作为开场副本放在彩条之前；然后从头播放完整正片，保留原顺序和原声。不要把片段从正文移动或删除，也不要自动挑选“最精彩”片段。结构为“指定高光副本 → 短彩条 → 完整正片”，检查高光/彩条到正文的接点，不吞掉正文起声前的准备空白，也不固定复用某条视频的时间点。当前是按配方辅助制作，没有标准化的一键片头执行器。
- 从原始素材和选段记录尽量一次导出，减少多轮压制。检查彩条进出、第一句起声、帧率与全片解码，并提供带正文衔接的短预览。
